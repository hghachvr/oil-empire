# 🛢️ Oil Empire

A hyper-casual idle/clicker game built with React + vanilla JavaScript. Extract oil, build your empire, and become the richest tycoon!

## 🎮 Features

- **Tap to Drill**: Click to extract crude oil barrels with satisfying animations
- **Auto Production**: Buy upgrades (machinery, workers, refineries) to earn passively
- **Processing System**: Barrels are processed automatically, then sell for $90 each
- **Combo Multipliers**: Rapid tapping gives temporary bonus multipliers
- **Rebirth System**: Reset progress to gain permanent ×1.2 earnings multiplier
- **Prestige Shop**: Unlock permanent upgrades with Prestige Points
- **Ad Rewards**: Watch ads for ×3 resource boost (10-20 min)
- **Offline Earnings**: Earn resources even when the game is closed
- **Bilingual**: Spanish (ES) & English (EN) support
- **Interactive Tutorial**: Complete walkthrough with highlighted UI elements
- **Mobile Optimized**: Works perfectly on iPhone with PWA support

## 📊 Game Progression

1. **Early Game**: Tap and buy basic upgrades (hand drill, pumps)
2. **Mid Game**: Unlock workers, refineries, and tankers for serious passive income
3. **Late Game**: Deploy sea platforms, pipeline networks, and AI drillbots
4. **Rebirth**: Reset to earn permanent multipliers and Prestige Points
5. **Prestige**: Buy permanent upgrades that boost all future runs

### Upgrades

- ⛏️ Hand Drill (tap bonus)
- 🔧 Oil Pump (1 bps)
- 👷 Worker (3 bps)
- 🏭 Mini Refinery (10 bps)
- 🚛 Oil Tanker (35 bps)
- 🛢️ Sea Platform (120 bps)
- 🔩 Pipeline Network (400 bps)
- 🛸 AI Drillbot (1500 bps)

### Prestige Upgrades

- 🪙 Golden Drill: +50% tap power
- 💨 Oil Rush: +100% auto production
- ⚫ Black Gold: +25% sell price
- 🚀 Mega Boost: Ad boost lasts 20 min instead of 10

## 🛠️ Tech Stack

- **React 18** (via CDN)
- **Babel** for JSX transpilation
- **localStorage** for persistent saves
- **requestAnimationFrame** for smooth game loop
- **CSS Grid & Flexbox** for responsive layout
- **Press Start 2P** font for pixel art aesthetic

## 📱 How to Play

### Desktop/Web
Simply open `index.html` in any modern browser.

### iPhone (Recommended)
1. Download or open `index.html` in Safari
2. Tap **Share → Add to Home Screen**
3. Play as a full-screen app!

Works offline once loaded.

## 💾 Save System

Game saves automatically every 10 seconds to `localStorage`. All progress persists across sessions:
- Barrels, dollars, upgrades
- Rebirths and Prestige Points
- Language preference
- Tutorial completion status

### Manual Save
Go to Settings ⚙️ → Save to force an immediate backup.
